URL del Google Apps Script

Esta URL conecta la plataforma con el Google Sheet. Se configura una sola vez por dispositivo.

Instrucciones de configuración

Para conectar el Sheet por primera vez:

1
Abrí el Google Sheet → Extensiones → Apps Script
2
Pegá el contenido del archivo Code.gs → guardá
3
Click en "Implementar" → "Nueva implementación" → "Aplicación web"
4
Ejecutar como: Yo · Acceso: Cualquier usuario
5
Copiá la URL y pegala en el campo de arriba
